# Ashfall-AirportDisruption

Code for creating fragility functions using airport closure duration and ashfall thickness data. For more details, please refer to: 

Lerner, G.A., Teng, N.R.X., Jenkins, S.F. et al. Impacts-based analysis of disruption to airport operations by volcanic ashfall. *J Appl. Volcanol*. 15, 7 (2026). https://doi.org/10.1186/s13617-026-00164-9
